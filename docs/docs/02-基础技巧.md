# 02-结构化 Prompt 框架与高级设计

> 本文档梳理了从零构建高质量 Prompt 的核心框架（CRAFT）、元提示词（Meta-Prompting）演进逻辑以及跨媒体 AI 工具链协同。

---

## 🔒 1. 为什么必须使用结构化 Prompt？

提示词本质上是给 AI 开具的**“新型规格说明书”**。

* **低质量 Prompt 痛点**：例如 *“写一封给健身房会员的投诉回复信，会员因为冻结会籍失败被扣款，正在生气”*。这类 Prompt 缺乏边界，会导致输出格式混乱、语调失当或遗漏关键业务条款。
* **结构化 Prompt 优势**：通过显式约束商业边界、目标受众、格式规范和事实核查机制，大幅降低 AI 幻觉，确保输出稳定性。

---

## 🛠️ 2. CRAFT 结构化框架详解

CRAFT 是落地商业场景最实用的五要素框架：

| 要素 | 名称 | 核心作用与描述 | 示例/填写指引 |
| :--- | :--- | :--- | :--- |
| **C** | Context (背景) | 提供行业背景、商业现状或参考资料来源 | "我是一家连锁健身房的客服主管..." |
| **R** | Role (角色) | 指定 AI 扮演的具体岗位或领域专家 | "扮演专业且富有同理心的客服专家" |
| **A** | Audience (受众) | 明确界定内容服务的目标客群与画像 | "针对因扣款失败而产生不满情绪的付费会员" |
| **F** | Format (格式) | 规定输出样式（表格/Markdown/特定字数/脚本） | "分为致歉、原因说明、解决方案三段式排版" |
| **T** | Task & Tone (任务与语气) | 描述具体的行动路径及传达的情感基调 | "撰写复核回复，语气真诚、专业且坚定" |
