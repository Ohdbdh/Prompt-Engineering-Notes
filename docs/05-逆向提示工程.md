# 🤖 逆向提示工程（Reverse Prompt Engineering）

> A structured reverse-engineering template to deconstruct content into reusable system prompts. 用于将各种内容解构为高复用性系统提示词的逆向工程模板。

---

## 📌 Usage / 使用方法

Copy the template below, fill in your specific requirements, and send it to the LLM to generate an optimized prompt.
复制下方模板并填入具体需求，发送给 LLM 即可生成优化后的专业提示词。

---

## 🎯 Universal Architecture / 通用底层架构

![Category](https://img.shields.io/badge/Category-Prompt--Engineering-blue) ![Version](https://img.shields.io/badge/Version-v1.0-brightgreen)

> 结构化提示词标准使提示词资产具备高度的可复用性、可维护性与跨场景迁移能力。

```text
┌────────────────────────────────────────────────────────┐
│                   【通用逆向工程 Prompt】                 │
├────────────────────────────────────────────────────────┤
│ 📌 固定不变项 (System Core)                             │
│   ├── Role: 专家角色定义                                │
│   ├── Objective: 逆向还原目标                           │
│   └── Workflow: 拆解步骤与输出规范                      │
├────────────────────────────────────────────────────────┤
│ 🧩 动态替换项 (Dynamic Variables)                        │
│   ├── {{FILE_TYPE}}      : 目标类型 (图片/文案/PPT/代码)│
│   ├── {{FRAMEWORK}}      : 4-6 个核心解构维度           │
│   ├── {{FEW_SHOT}}       : 高质量参考示例               │
│   └── {{INPUT_CONTENT}}  : 待分析的实际内容             │
└────────────────────────────────────────────────────────┘
