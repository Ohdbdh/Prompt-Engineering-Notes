# 🤖 逆向提示工程（Reverse Prompt Engineering）

> 结构化提示词标准使提示词资产具备高度的可复用性、可维护性与跨场景迁移能力。

## 🛠️ 通用逆向工程 Prompt 架构

```text
┌────────────────────────────────────────────────────────┐
│                   【通用逆向工程 Prompt】                 │
├────────────────────────────────────────────────────────┤
│ 📌 固定不变项 (System Core)                             │
│   ├── Role: 专家角色定义                                │
│   ├── Objective: 逆向还原目标                           │
│   └── Workflow: 拆解步骤与输出规范                      │
├────────────────────────────────────────────────────────┤
│ 🧩 动态替换项 (Dynamic Variables)                        │
│   ├── {{FILE_TYPE}}      : 目标类型 (图片/文案/PPT/代码)│
│   ├── {{FRAMEWORK}}      : 4-6 个核心解构维度           │
│   ├── {{FEW_SHOT}}       : 高质量参考示例               │
│   └── {{INPUT_CONTENT}}  : 待分析的实际内容             │
└────────────────────────────────────────────────────────┘

### 📝 Prompt Content / 提示词内容

💡 使用方法：复制下方代码块，将其中的 {{ 变量 }} 替换为对应场景的内容即可使用。
```markdown
# Role
你是一位专业的逆向提示工程专家（Reverse Prompt Engineer）。

# Objective
请分析用户提供的 [{{FILE_TYPE}}]，按照【提取框架】深入拆解核心要素，并生成能够精准重构该内容的详细中文 Prompt。

# Instructions
1. 深入分析用户传入的内容，严格对照【提取框架】逐一提取细节，拒绝笼统描述。
2. 按照【输出格式】组织内容，确保用词准确、可复用性强。

# Extract Framework (提取框架)
{{FRAMEWORK}}

# Output Format (输出格式)
请直接按以下格式输出提取结果：
[维度 1]: ...
[维度 2]: ...

---
# Few-Shot Example (参考示例)
{{FEW_SHOT}}

---
# Target Input (待分析对象)
[ {{INPUT_CONTENT}} ]
```


#### ⚙️ 场景模版生成器 (Meta-Prompt)
💡 说明：当遇到上述卡片库没有的新场景时，发送此段代码给 AI，它会自动为你生成新的逆向模板。
```markdown
# Role: 结构化提示词架构师
# Objective: 根据用户输入的 [应用场景]，自动构建标准的“逆向工程 Prompt 模板”。

# Instructions:
1. 提炼该场景下最关键的 4-6 个解构维度（遵循 MECE 原则）。
2. 提供一个极具代表性、细节丰满的 Few-Shot 案例。
3. 按照“通用模板格式”输出可直接复制的最终提示词。

# Input Scene:
[请在此输入新场景，例如：短视频爆款分镜逆向 / UI 界面逆向]
```
